# 文档离线识别入库引擎（全平台版）v1.0

**一句话**：在自己电脑上把一批材料离线读成能用关键词搜索的正文库，材料不用上传任何网站。

- 本仓库发布的是**全平台技能包**（Windows / macOS / Linux，包内自带 7 平台离线解析组件）。
- 因为第三方平台上架有「**单文件 ≤ 6 MB**」的硬限制，而包内解析组件单件就有 7.89 MB，本版本**无法在平台上架**，改在这里提供下载。
- 平台上架版（不含体积大的解析组件，功能与流程完整）：见平台页面（链接待补）。

## 用法（三步）

1. **解压** zip，得到目录 `文档离线识别入库引擎/`。
2. **装依赖**：在该目录内执行 `python tools/setup_env.py --all`
   （需要 Python 3.10+；离线识别依赖约 265 MB，装一次长期可用）。
3. **体检**：`python tools/setup_env.py --check` → 看到「✅ 可以跑全链路」即可开始。

具体怎么喂材料、产出什么、有哪些开关，见包内 `SKILL.md`。

## 它产出什么

- 一个能用关键词检索的**正文库目录**（纯文本，系统搜索或 grep 即可查）；
- 一张**覆盖度审计表**：这批材料覆盖了哪些要求条目、哪几条还没被覆盖，用于判断资料是否齐套。

## 三个好处

- 全程在本机跑，**材料不出网**；
- 中途断了能**接着跑**，不用从头来；
- 几十上百份**一起处理**，不用一份份点。

## 实测参考

一批 100 份 / 3,417 页，约 3.85 秒一页，识别置信度 0.96–1.00，**全程不联网**。
